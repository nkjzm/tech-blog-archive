Aqua Voiceの音声入力で、文章の最後に付く「。」を消したくなりました。
「ごめん」と話したときは「ごめん」と入力してほしい。
ただし、2文以上話したときは、途中の句点を残したいです。

カスタム指示に句点を省略するよう書いても、付いたり付かなかったりしていました。
そこで、Codexと相談しながら指示を変え、実際に話して確かめてみました。

## うまくいったカスタム指示

今回、意図した出力になったのは次の指示です。
Aqua Voiceのカスタム指示に設定します。

```text
出力を完成させた後、最後に次の処理を行う。
- 出力の最後の文字が「。」なら、その1文字だけ削除する。
- 途中にある「。」は残す。
- 最後の文字が「？」「！」なら変更しない。

変換例:
眠い。 → 眠い
雨が降っている。傘を持っていこう。 → 雨が降っている。傘を持っていこう
```

これはカスタム指示による整形で、外部のスクリプトで文字を削除しているわけではありません。
「最後に処理する」と書いていますが、Aqua Voiceの内部で本当にその順番で処理されているかは確認していません。

## 出力例を付けても句点が残った

最初は、句点を付けないルールに「ごめん」「ありがとう」などの例を添えました。
その後、途中の句点を残すために「出力全体の最後の句点だけ省略」と指定し、良い出力例と悪い出力例も入れました。

[Aqua Voiceの公式ガイド](https://aquavoice.com/guide/custom-intructions)でも、ルールを箇条書きにし、望ましい出力例と望ましくない出力例を添える形式が推奨されています。
ただ、今回試した範囲では、それだけでは意図した結果になりませんでした。

実際の出力は次のとおりです。

```text
おはよう。
助かった。
難しいね。
荷物が届いた。
今日は寒いね。暖房をつけよう。
駅に着いた。改札の前で待ってる。
```

短い返答でも、2文の発話でも、末尾に句点が残っています。
当初は短い発話で失敗しやすいと感じていましたが、この結果だけから短文固有の問題とは判断できません。

## 「★」で指示が反映されるか確認した

次に、句点の指示を工夫する前に、カスタム指示への変更が出力に反映されるか試しました。
一時的に次の指示を設定しました。

```text
すべての出力の末尾に「★」を追加する。
例: お疲れさま★
```

「そろそろ寝よう」と話した結果がこちらです。

```text
そろそろ寝よう。★
```

「★」は追加されました。
少なくとも、この指示による出力の変化は確認できました。
ただし、これだけで句点のルールが失敗した原因や、内部の処理順が分かるわけではありません。

そこで「★」の指示を外し、冒頭の「最後の文字が『。』なら、その1文字だけ削除する」という指示を試しました。

## 指示に含めていない言葉でも試した

変更後は、次の出力になりました。

```text
雨が降っている。傘を持っていこう
そろそろ寝よう
```

どちらも末尾の句点がなくなりました。
ただし、最初の文はカスタム指示の変換例に含まれています。
そこで、変換例に入れていない言葉でも追加で試しました。

| 発話内容 | 実際の出力 |
| --- | --- |
| おやすみ | おやすみ |
| なるほどね | なるほどね |
| お腹すいた | お腹すいた |
| 洗濯が終わった | 洗濯が終わった |
| 充電が少ない。ケーブルを探そう | 充電が少ない。ケーブルを探そう |
| 道が混んでいる。少し遅れそう | 道が混んでいる。少し遅れそう |
| 窓を開けた。風が気持ちいい。もう少し休もう | 窓を開けた。風が気持ちいい。もう少し休もう |
| 鍵は持った？ | 鍵は持った？ |

表の発話内容にある句読点は、読みやすさのために付けたものです。
「まる」と発音して入力したものではありません。

この8例では、短い返答の末尾に句点が付かず、複数文の途中の句点は残り、末尾の疑問符も残りました。
感嘆符の保持は指示に含めていますが、この8例では確認していません。

なお、同じ音声を使った比較や、各例を何度も繰り返す試験はしていません。
アプリのバージョンや入力モードも記録していないため、今回の結果だけで再現率や成功の原因までは断定できません。
同じ悩みがある場合に試せる指示の一例として読んでもらえればと思います。

## カスタム指示が効かないときに試したいこと

今回の試行では、望む文体を伝える指示から、対象の文字と操作を指定する指示に変えたところ、意図した出力を確認できました。
他のカスタム指示で困ったときも、次の順で試すと、どの変更で出力が変わったかを確認しやすそうです。

1. 消したいものと残したいものを区別する。今回は「最後の句点」と「途中の句点」。
2. 一時的に目立つ目印を出力させ、指示への変更が反映されるか試す。
3. 「最後の文字が『。』なら1文字削除」のように、条件と操作を具体的に書く。
4. 指示に載せた例文だけでなく、別の短文や複数文でも確かめる。
